# Xiaomi Mi TV Stick 4K (2nd gen) (MiTV-AFMU1, codename adastra, device twilight), Android TV 14 (Google TV),
# SDK 34, firmware UKG3.250826.001.V816.0.7.0.UZFAATK. 1.9 GB RAM, /system is full (100%), so nothing frees there.
#
# Apply:   TV_HOST=<tv ip> tools/disable.sh examples/xiaomi-mi-tv-stick-4k-gen2/debloat.txt
# Undo:    TV_HOST=<tv ip> tools/restore.sh examples/xiaomi-mi-tv-stick-4k-gen2/debloat.txt
# Everything is DISABLED, not uninstalled. Comment out any line you want to keep.
#
# Tested for one day, in batches with screenshots between them, then a reboot. Treat this as provisional
# until it has been used for a few days (CONTRIBUTING.md).
#
# Already disabled by the firmware before any change (not listed): Netflix, Prime Video, Mi channels
# (michannel, atv), Google calendar sync, partner setup, Talkback, Health Connect controller.
# Removed for user 0 by the firmware after the first reboot (not listed): YouTube Music and Mi Plus.
#
# Notes from this stick:
# - Stock launcher com.google.android.apps.tv.launcherx must go, but disabling it alone makes Home resolve to
#   setupwraith's RecoveryActivity. Disable setupwraith in the same list, after checking
#   `dumpsys wifi | grep -o 'cname=[^ ]*'`: here the saved network belonged to android.uid.system, so it
#   stayed on Wi-Fi. If it belongs to setupwraith, forget and re-join the network first.
# - build-and-install.ps1 disables launcherx after the new launcher takes Home; run this list after that.
# - Mi TV Stick 4K gen 2 with the cleanyourtv launcher: install with launcher/build-and-install.ps1 -TvHost <ip>.
# - Wireless debugging (port 41817, TLS) is not supported by tools/tv.py; use USB debugging on port 5555.
# - Network debugging was off after a reboot here (observed once); re-enable it before running the tools.
# - Keeping on purpose: Google Play Store, Play Services, TV input and remote services, Bluetooth, Droidlogic.
#
# Kept by choice, re-enable if you want them:
# - com.google.android.youtube.tv: NOT disabled by this list. The YouTube app stays enabled.
# - com.google.android.apps.mediashell (Chromecast), com.google.android.katniss (Google Assistant voice),
#   com.google.android.apps.tv.dreamx (Google ambient screensaver, replaced by the launcher clock screensaver).
# - com.xiaomi.mitv.updateservice: DISABLED by this list. The TV will not offer firmware updates.
#   Re-enable it (pm enable --user 0 com.xiaomi.mitv.updateservice) to check for updates.
# - Casting (smartshare, wfdsinkhelperservice, mi_connect_service) is off here. Phone casting was not tested.
